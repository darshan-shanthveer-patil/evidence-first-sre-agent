# Evidence-first SRE agent

An experimental, read-only incident investigation agent for Kubernetes
workloads. It turns observations from operational systems into ranked,
auditable hypotheses without presenting guesses as facts.

The first milestone is intentionally deterministic. It establishes the
evidence contract, evaluation fixtures, and safety boundaries before an LLM is
introduced. This gives future agent behavior a testable baseline.

## What works today

- Diagnoses OOM kills, crash loops, probe failures, Service selector mismatches,
  and CPU saturation from captured evidence.
- Ranks multiple plausible causes by confidence.
- Shows exactly which observations support each claim.
- Separates verification checks from low-risk operational actions.
- Returns an explicit `inconclusive` result when the evidence is insufficient.
- Produces human-readable or JSON output without external dependencies.

## Quick start

Python 3.11 or later is required.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
sre-agent examples/incidents/service-selector-mismatch.json
```

Use `--json` when feeding the report into another tool:

```bash
sre-agent examples/incidents/oomkilled.json --json
```

Run the test suite with the Python standard library:

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

```text
Incident: inc-2026-002

```

## Project direction

The intended system is an agentic investigation loop, not a chatbot around
`kubectl`. Each stage must remain inspectable and independently testable:

1. Collect read-only Kubernetes state.
2. Query bounded Prometheus time windows.
3. Normalize observations into the evidence contract.
4. Generate and challenge hypotheses.
5. Record evaluation results in MLflow.
6. Allow policy-approved dry runs only after read-only behavior is reliable.

See [docs/architecture.md](docs/architecture.md) for boundaries and design
decisions.

## Non-goals for the current milestone

- Direct production mutations
- Shell access generated by a language model
- Unbounded observability queries
- A diagnosis without supporting evidence
- Treating confidence as statistical probability
